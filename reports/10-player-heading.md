# 차량 앞뒤 방향 수정 · 2026-09-08

## 원인과 변경

- 주행 진행률·서킷 접선·뒤쪽 카메라의 부호는 일치했으나, Meshy 플레이어 GLB의 앞쪽 축을 `+X`로 잘못 선언했다. 실제 모델의 앞날개·코는 `-X`에 있다.
- `app/RaceScene3D.tsx`: 플레이어 모델의 앞쪽 축을 `-X`로 바꿔 차량을 기존 대비 180° 회전했다. 공통 생성 경로를 사용하므로 20대 그리드의 내 차와 두 전략 비교의 내 차에 모두 적용된다.
- 전략·페이스·피트·순위·진행률·카메라 위치 계산은 수정하지 않았다. 상대 차량 모델의 설정도 그대로다.

## 회귀 검사

- `tests/race-camera.test.mjs`: 실제 GLB를 읽고 실제 `createFormulaCar` 정규화를 거친 앞/뒤 기준점과 주행 변위를 비교한다. 모델 파일 해시를 고정해 파일 교체 시 앞뒤 의미를 다시 검수하도록 한다.
- 내 차의 코가 이동 방향을 향하는지, 추적 카메라는 뒷부분에 더 가까운지, 추적·콕핏 시선은 전방인지 검사한다. 그리드 유무와 네 주행 시점을 포함한다.
- 이전 `+X` 설정을 주입하면 같은 방향 검사가 실패하는 음성 대조군을 추가했다. 이전 카메라 거리 검사는 빈 그룹을 사용했으므로 이 오류를 발견할 수 없었다.
- 카메라 검사 **6/6 PASS**. 최초 격리 실행의 샌드박스 자식 프로세스 제한은 비격리 실행으로 확인했다. 최종 전체 실행은 자식 프로세스 실행이 허용된 환경에서 `node --experimental-strip-types --test tests/*.test.mjs`로 재검증했다: **203/203 PASS, 실패·취소·건너뜀 0, 80.777초**. 기존 건식·우천 DP ↔ 완전탐색 검사도 통과했다.

## 화면 검수

- 로컬 프로덕션 빌드, 앨버트 파크·레드불, 1배속과 60배속의 전체 주행 화면을 직접 확인했다. 앞날개 대신 뒷날개가 카메라 가까이에 있으며 코는 전방을 향한다.
- 콕핏 시점은 진행 방향을 바라본다. 60배속 20랩에서도 앞뒤 방향과 가까운 추적 거리가 유지됐다.
- 전체화면 종료와 일시정지 확인, 브라우저 오류·경고 없음. 타입 검사·ESLint·프로덕션 빌드 PASS. 기존 큰 번들 경고는 유지된다.
- 실제 GPU 화면의 앞/뒤 의미는 수동 시각 검수다. 자동 검사는 해시가 고정된 모델의 검수된 축을 전제로 하며, 임의의 새 3D 모델에서 코를 자동 식별하지 않는다.
