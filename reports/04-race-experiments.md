# 4절 · 대표 후보와 재현 가능한 레이스 실험

- 변경: representative-strategies, race-experiments, shared-race-grid, RaceExperimentPanel/CSS/Worker, RaceReplay 공유 그리드 소비자, StrategyLab 연결, 관련 tests와 tools/README-race-experiments.
- 상수: params.race의 300회·시드·20대·SC 55%·VSC 70%·1초 교통 창·0.4 손실 비율·RAC 추월식·3랩 정산·0.5초 대안 간격. 확률과 시간 매핑은 프로젝트 규칙이다. 공식 상태 기록 빈도는 별도 자료 수집 후 출처를 유지해 추가한다.
- 검사: index 추출본 131개 중 알고리즘/그리드/Worker 등 130 PASS, 피트 원시자료의 수집시각 버전과 summary가 다르게 stage된 1건 FAIL. 두 원본을 같은 버전으로 묶어 수정 후 해당 5개 모두 PASS. TypeScript PASS. 기존 DP↔완전탐색 PASS. 최종 전수 재실행은 9절에서 기록한다.
- DOM: ‘1번은 기존 K-best DP의 최단 해’, ‘2·3번은 … 전역 2·3위가 아닙니다’, ‘3D와 20대 참가자·출발 순번·상대 전략·능력치 기초 랩 비용을 공유’ 표시 확인. 300회 Worker 계산 완료, P10–P90/후보 내 승률/가상 그리드 승률/공통 회차 선택을 실제 브라우저에서 확인했다.
- 구현: 그룹별 스틴트 DP + 한 피트 경계 이동 후보 풀로 순열 중복을 제거한다. 원래 K-best의 전역 최단을 재평가·보존하며 기존 최적화 코드는 변경하지 않는다. 한 회차에 후보·상대 모두 같은 SC/VSC 타임라인과 ID 기반 공통 난수를 사용한다. 상대 19대의 비용은 능력치만 적용한 상태로 전달하므로 이미 계산된 교통을 다시 더하지 않는다.
- 한계: 대안 2·3번은 대표 후보이며 전역 2·3위가 아니다. 교통/SC까지 포함해 DP를 다시 최적화하지 않는다. SC 대열 압축과 실제 전체 주행 지연은 미구현이다. 서로 다른 두 레이스 엔진은 출발 입력을 공유하지만 같은 총시간을 보장하지 않는다. 고정 시드로 재현되는 결과는 현실 예측의 정답을 뜻하지 않는다.
