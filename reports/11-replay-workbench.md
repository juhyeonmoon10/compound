# 시뮬레이션 조작 UI 개선 · 2026-09-08

## 적용 범위

- 시뮬레이션 탭에서만 큰 선수·차량 소개 영역과 반복 조건 설명을 접고, 짧은 서킷·선수·전략 요약 및 조건 변경 버튼을 제공한다. 다른 연구 탭의 배치는 유지한다.
- 주행 화면 바로 아래 하나의 조작 바에 재생·정지, 이전/다음 랩, 1·10·30·60배속, 카메라, 전체화면, 처음부터를 모았다. 초기 배속은 1배다.
- 재생 중에도 탐색 막대·컴파운드 구간·피트 표식을 유지한다. 시간 탐색은 일시정지하며, 이전/다음 랩과 피트 표식은 그리드·교통·피트 대기 손실이 반영된 실제 재생 시계를 사용한다.
- 전체화면 대상은 주행 영역이다. 조작 바는 마우스·터치·포커스로 표시되고 주행 중 약 2.6초 후 숨겨진다. 키보드 조작 중인 컨트롤은 숨기지 않는다. 포인터로 누른 버튼은 주행 영역으로 포커스를 돌려 자동 숨김을 재개한다.
- 속도계는 우하단으로 옮겼다. 전체화면에서는 측정한 조작 바 높이만큼 HUD를 띄우며, 낮은 가로 화면에서 조작 바를 열면 충돌하는 순위표·미니맵·보조 HUD를 잠시 숨긴다.
- 순위표를 접을 수 있고, 좁거나 낮은 화면에서는 내 차와 가까운 두 상대만 표시해 내 차가 P7 이후여도 빠지지 않게 했다.
- 계산 기준·출처, 차량 상세, 레이스 기록은 선택해서 여는 측면 패널로 이동했다. 기존 20대 기록·타이어 구간·이벤트와 전략 비교를 유지했고 이벤트 시점 이동을 추가했다. 상세 패널은 전체화면 대상 밖에 있다.
- 화면 밖/다른 탭으로 이동해 자동 정지되었을 때 이유를 화면에 표시한다. 시작·재시작 시 카메라와 배속을 유지한다. 처음부터는 확인창을 거치고, 취소하면 직전 상태로 돌아간다. 취소된 출발 카운트다운은 정지 상태, 이미 완주한 경기는 결과 상태로 복원한다.
- Space(재생·정지), C(카메라), F(전체화면)는 리플레이에 포커스가 있을 때만 동작한다. 입력창·버튼·선택 상자·대화상자의 기본 키 동작과 한글 입력은 가로채지 않는다.
- 3D 로딩 중에도 이미 시작한 재생은 일시정지할 수 있다. 종료 결과창은 높이를 제한하고 내부 스크롤을 제공해 작은 화면에서도 재도전·전략 수정·데이터 분석에 접근할 수 있도록 했다.

## 유지한 내용

타이어 전략 계산, Top 3 추천, 팀 강조색 및 고정 타이어 색, 차량 GLB와 방향·카메라 물리·속도 모델은 변경하지 않았다. 차량 그래픽 개선은 이번 범위에 포함하지 않았다. 개인 `juhyeonmoon10/compound`만 변경하며 팀 저장소에는 반영하지 않는다.
