# 8절 · 실험 조건 저장과 두 기록 비교

## 변경 파일과 저장 계약

- `app/lib/experiment-notebook.ts`: 저장 envelope v2와 선택적 `ExperimentResearchInfo`를 추가했다. 기존 저장 키 `apex:experiment-notebook:v1`은 유지하며 v1/v2 모두 읽는다. 기존 유효 v1 필드를 보존하고 과거에 없는 강수·시드·능력치 값은 만들지 않는다.
- `app/ExperimentNotebook.tsx`, `app/experiment-notebook.css`: 현재 조건 미리보기, 기록 목록, 두 실험 조건·결과 비교표, 5종 타이어 표시. 상위에서 `research` prop을 전달할 수 있다. `fastf1-2025` 식별자는 호환을 위해 유지하고 표시 문구만 ‘FastF1 2023–2025 학습 계수’로 변경했다.
- `tests/experiment-notebook.test.mjs`: 직렬화·호환·입력 검증·중첩 복사·조건 차이·CSV 보호 회귀 검사.
- `StrategyLab.tsx`와 `app/lib/notebook-research.ts`에서 조건/EA 출처/선택 시행/MC 스냅샷을 연결했다. 현재 전략의 전체 서명과 시드가 일치하는 완료된 실험만 저장한다. 직접 설계 또는 다른 전략·시드의 결과에 추천 후보의 승률을 붙이지 않는다. `tests/notebook-research.test.mjs`에서 실제 계산→저장→복원까지 검사한다.

저장하는 추가 조건은 해석된 강수 프리셋·비 시작/끝 랩·초기 수막·차량 수, uint32 시드, SC/VSC 요약 문자열, 팀·선수 ID, 능력치 적용 여부다. 선택적으로 MC 시행 수·후보 중 승률·P10/P90, EA 원점수·iteration·확인일·URL을 보관한다. MC 실행 여부나 과거 기록의 미기록 상태를 0% 승률 같은 결과로 바꾸지 않는다.

## 상수와 결과 해석

- 기존 저장 한도 `MAX_EXPERIMENTS=20`, 이름 100자, 저장 envelope 버전 2. 저장소 용량이 넘치거나 기록이 손상되면 과거 항목을 자동 삭제하지 않는다.
- 시드 범위는 `MODEL_PARAMS.race.uintRange`에 따른 0~2³²−1이다. 강수 기본값은 `buildWeatherTimeline`으로 확정한 뒤 복사해서, 후속 기본값 변경으로 과거 기록의 뜻이 바뀌지 않도록 한다.
- 5종 컴파운드는 `TYRE_LABELS`의 `S/M/H/INTER/WET`만 허용한다. UI의 `I/W` 약자는 저장 ID가 아니다. 의미 색은 `TYRE_COLORS`를 그대로 사용한다.
- 비교 시간은 두 번째 선택−첫 번째 선택이다. 서킷·랩·계수·피트·열화·온도·제약·전체 모델 서명과, 강수·시드·SC 요약·팀·선수·능력치·시행 수·EA 스냅샷 차이를 확인한다. 입력이 다른 두 기록의 시간 차이를 전략만의 효과로 해석하지 않는다.
- MC 승률과 P10/P90 차이는 결과 차이이며 그 자체로 조건 변경은 아니다. 승률은 입력 후보 중 최단시간 비율, 분위수는 시뮬레이션 분포이며 현실 우승 확률·신뢰구간이 아니다.

## CSV와 원본 보호

CSV는 기존 17열+추가 23열의 총 40열이다. UTF-8 BOM, CRLF, 쉼표·따옴표·개행 인용 처리를 유지한다. `=`, `+`, `-`, `@` 등으로 시작하는 문자열에는 수식 실행 방지를 적용하되 음수 숫자의 의미는 보존한다. v1의 미기록 조건 열은 비워 둔다.

읽을 수 없는 버전·손상 기록·중복 ID를 감지하면 UI는 원본 보호를 위해 저장·삭제를 막는다. 읽을 수 있는 기록만 CSV로 내보낼 수 있다. 최대 20개에서 새 기록 저장을 거절하며 가장 오래된 기록을 자동 퇴출하지 않는다. 정상 저장 시 기존 기록과 함께 v2 envelope로 직렬화한다.

## 남은 한계

- 브라우저 원점별 로컬 저장이며 서버/기기 간 동기화가 없다. 브라우저 데이터 삭제 시 기록이 사라진다.
- CSV는 내보내기만 제공하며 다시 가져오기나 전체 JSON 백업 기능은 없다.
- SC/VSC는 요약 문자열이며 매 시행의 모든 원장·상대 19대 전략·코드/자료 버전 전체를 저장하지 않는다. 같은 시드를 보관해도 코드나 자료가 바뀌면 예전 실행 전체를 CSV만으로 복원할 수 없다.
- v1에 없는 조건을 소급 추정하지 않는다. 두 v1 기록끼리는 당시 모델 서명을 비교할 수 있지만, 기록되지 않은 연구 조건까지 검증했다는 뜻은 아니다.
- 로컬 저장은 사용자 소유 브라우저 데이터로, 계정 인증이나 암호화된 개인 금고가 아니다. 실측 레이스 결과와 저장된 모델 예측은 구분해야 한다.
