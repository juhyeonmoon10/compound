## 브라우저 검수 근거

- 프로덕션 빌드의 실제 미리보기에서 서킷 24개와 11팀 선택지를 확인했다. 앨버트 파크→질 빌뇌브, 레드불→페라리 변경 시 URL·70랩·실제 차량 이미지·강조색이 함께 갱신됐다. 타이어 초록/파랑은 팀 빨강과 독립적이었다.
- 강한 비·최대 3스톱 조건에서 `인터미디어트 → 웨트 → 웨트`, L6/L38 교체, 실제 우천 타이어 사용에 의한 규칙 면제를 확인했다. 최대 3회는 허용 상한이지 반드시 3회 교체하라는 뜻이 아니다.
- 상세 차트에 비 음영과 오른쪽 수막 축 0·0.5·1이 있다. 우천 랩 표에서 온도/그립/마모율 모두 `미모델링`, 이전 건조 0랩은 `과열 누적 없음`, 이후 비용 이력은 `과열`로 표시됐다.
- 우천 자료 후속 화면에서 기존 5개 동랩 비교와 74건 실제 슬릭↔인터 종류 전환을 확인했다. 영국 4개 비교점과 타이어별 표본 수, 공식 원문 링크, Q1/중앙값/Q3를 표시한다. L9와 L40 사이에 비교 관측이 없으므로 정확한 교차 랩은 제시하지 않는다. 모바일 문서 폭도 375px로 넘침이 없었다.
- 타이밍 20명, 내 차 강조, 스틴트 피트 마름모, 출발 대기/주행 전환을 확인했다. 전체화면은 주행 화면과 최소 재생 제어만 남기고 기록 패널과 상세 차트를 제외했다. 전체화면 속성이 도구에 노출되지 않아 네이티브 API와 CSS 대체 모드의 구분 검증은 하지 않았다.
- 60배속에서 카메라가 차량의 이동을 뒤늦게 따라가 내 차가 멀어지는 문제를 수정했다. 같은 몬트리올 주행을 전후 비교해 내 차가 화면 아래 가까운 위치에 유지되는 것을 확인했다. 추적·콕핏 시점의 네 배속·세 프레임률 검사는 실제 렌더 프레임 함수를 사용하되 GPU 렌더링 검사는 아니다.

## 검수 중 바로잡은 문제

- 비가 왔다는 이유만으로 건식 1종 전략을 합법 처리하던 백테스트 규칙을 실제 INTER/WET 사용 기준으로 수정했다.
- 우천 타이어를 항상 최적·65°C·그립 100%로 표시하던 잘못된 센서형 수치를 미모델링으로 구분했다. 랩타임 비용을 중복 추가하지 않았다.
- ‘SC 55%, VSC 70% 할인’을 ‘정상 손실의 55%, 70% 적용’으로 수정했다.
- 기존 v1 기록의 학습 연도를 소급 확정하지 않도록 노트의 계수 이름을 `FastF1 관측 보정 계수`로 표시했다. 팀 이름도 한국어로 통일했다.
- 새로운 검증 항목과 5종 타이어 모델에 맞춰 알고리즘 설명·상태·의사코드를 갱신했다.
- 무거운 백테스트·확률 실험은 Worker, 관측 원자료는 필요할 때 읽도록 분리했다. 검사 스냅샷 `work/`는 ESLint 대상에서 제외하고 기존 미사용 타입 경고를 제거했다.

## 완료로 주장하지 않는 항목

- 우천 수막 센서 자료, 충분한 WET 동랩 비교, 실제 교차 수막 보정은 없다. 제공 식의 전환은 0.10 초과/0.60이며 요청 예시 0.12/0.55나 ‘검증된 값’을 근거 없이 복사하지 않았다.
- 공식 최근 5경기 팀 페이스 차트 55값과 독립 피트 정차 시간이 미확보다. 차트 값은 null, 피트크루 보정은 중립 0초로 구분한다. 차량 성능 자체의 인과 추정이 아니라 정제 랩 기반 프로젝트 보정이다.
- β 회귀 보정은 완료됐지만 실측 클리프 시작 랩 식별은 미완료다. 기존 급락 임계점은 가정이다. 21경기 회귀의 시간순 홀드아웃 오차와 7경기 전체시간 오차는 다른 지표이며 일부 경기가 학습과 겹친다.
- SC/VSC 관측 137/173경기, 빈도 채택 15/24서킷이다. 2022 접근 거절·초기 상태 누락·2021 스파 특수 경기 등을 무사건으로 처리하지 않았다. 실제 다중 사고·대열 압축·SC 감속·재출발·적기를 재현하지 않는다.
- 보드는 요청된 핵심 좌표·치수를 사용하되 공식 제휴를 암시하는 공동 로고나 모든 대회의 스폰서 포함 정식 대회명을 복제하지 않았다. 좁은 교체 구간의 문구는 잘리지 않도록 위치를 조정한다.
- 3D는 실제 서킷 윤곽 기반 기존 그래픽이다. 차량 물리·정확한 고도·상용 레이싱 게임 품질을 새로 구현한 것이 아니다. 정적 자산과 3D 묶음에는 번들 크기 경고가 남는다.
- 실험 노트는 로컬·최대 20개, CSV 내보내기 전용이다. 전체 모델·모든 시행 원장을 저장하지 않으므로 코드/자료 버전이 바뀐 뒤 CSV만으로 완전한 재실행을 보장하지 않는다.
