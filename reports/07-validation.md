- `app/StrategyBacktestPanel.tsx`, `app/workers/backtest.worker.ts`, `tests/backtest-worker.test.mjs`, `tests/strategy-backtest.test.mjs`: 무거운 우천 탐색을 Worker로 분리. 경기 변경·취소·캐시·늦은 응답·오류·재시도를 검증했다. 패널과 자료는 검증 탭 진입 시 불러온다.
- `app/StrategyLab.tsx`: 원래 4개에 고정 7개와 현재 비용 합계 검사를 연결하고 5종 타이어·실제 우천 타이어 사용 여부를 포함한 알고리즘 설명으로 갱신했다.
- 검수 중 발견한 `app/lib/tyre-state.ts`의 우천 상태는 무조건 최적/그립 100% 대신 실제 이전 건조 랩 누적을 표시한다. 온도·그립·마모율은 미모델링으로 구분했다. `strategy.ts`는 기존 dryAge 전달만 추가하며 랩타임 식을 바꾸지 않았다. `RaceReplay.tsx`, 상세 표, `tests/tyre-state.test.mjs`에 반영했다.

## 상수·출처

- `params.validation`의 기준은 프로젝트 회귀검사 임계값이다. 연료 효과 1.2–3초, 소프트 25번째/5번째 랩 차 2초, 바레인 교체 L20→21 차 0.3초, 오차 허용값과 수막 검사 간격을 중앙 관리한다. `pitSensitivityAfterLap=20`은 통제 사례의 랩 번호이며 모든 전략에서 차이를 보장하지 않는다.
- 연료 차분 2.850초, 소프트 총 열화 차 4.472초(클리프 단독 1.550초), 피트 1랩 이동 0.764초는 지정 모델 계산 결과다. 실측값이 아니다.
- 제공 식의 슬릭→인터 경계는 수막 0.10 초과의 불연속 전환, 인터↔웨트는 0.60이다. 요청 예시 0.12/0.55를 통과시키기 위해 식이나 검사를 조작하지 않았다.
- FIA 건식 2종 의무 면제는 실제 INTER/WET 사용으로 판정한다. 비가 왔다는 이유만으로 면제하던 백테스트 생성기 오류를 수정했다.

## 검사·화면 근거

- 알고리즘 30 + 우천 6 + 추가 검증 7 + 백테스트 7 + Worker 6 = **56 PASS, 0 FAIL**. 건식·우천 DP ↔ 완전탐색 포함. 별도 우천 상태 검사를 포함한 관련 검사도 42 PASS, 0 FAIL이다.
- 중간 TypeScript 검사에서 아직 반영되지 않은 nullable 우천 UI 오류 11건이 검출돼 수정했다. 이어 한국어 서킷명 접근에서 TrackModel 타입 오류 1건을 발견해 현재 선택 조건이라는 정확한 표시로 수정했다. 최종 전체 검사를 9절에서 반복한다.
- 실제 브라우저에서 기존 4개와 추가 8개 모두 `통과`, 연료 `2.850초`, 소프트 `4.472초`, 피트 `0.764초`, 경계 `0.10`·`0.60` 표시를 확인했다.
- 실제 7개 경기 선택 버튼과 오스트리아 실제시간 `1:23:47.7`, 모델시간 `1:23:09.9`, 절대 오차 `0.75%`를 확인했다. 영국 선택 시 `전략을 별도 작업에서 계산하고 있습니다`와 취소 버튼이 나타나며 화면 조작이 유지된다.

## 남은 한계

- 실제 총시간에 맞춰 기준 랩을 역산하지 않는다. 영국 우천 경기는 약 14–15% 오차이며 SC 감속·재출발·강수의 정밀 이력 미모델링을 포함한다. 결과가 좋아 보이도록 경기나 오차를 숨기지 않는다.
- 7개 경기 일부가 회귀 학습 자료와 겹치므로 독립된 미학습 GP 검증이 아니다. 시간순 랩 홀드아웃 MAE와 전체 경기 오차는 별개다.
- 중고 타이어 초기 나이는 관측 표시하지만 현재 백테스트는 새 세트로 정규화한다. 클리프 임계 시작 랩의 실측 식별은 완료되지 않았으며 유의한 2차 열화 보정과 구분한다.
- 백테스트 원본 K-best 상위 3개는 순서만 다른 동률을 포함할 수 있다. 메인 보드의 중복을 묶은 대표 대안과 의미를 구분한다.
